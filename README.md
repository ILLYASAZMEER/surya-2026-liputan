# Jadual Liputan SURYA 2026

Website jadual liputan untuk Pasukan Coverage, Media Sosial JKR Sarawak, sepanjang Karnival Sukan JKR Se-Malaysia (SURYA 2026), 1–5 Disember 2026, Kuching & Kota Samarahan.

- **Jadual:** 109 slot untuk 10 sukan dan 2 majlis rasmi, boleh ditapis ikut hari, sukan dan petugas.
- **Ketibaan:** masa ketibaan penerbangan 17 kontinjen ke Kuching (29 Nov – 3 Dis), ikut tarikh, dengan no. penerbangan, bilangan peserta dan sukan. Sumber: Master Tracker Accommodation SURYA 2026 (tab ARRIVAL (TIME IN ORDER) + tab zon). Boleh disalin untuk WhatsApp. Admin boleh menetapkan petugas liputan bagi setiap ketibaan (dengan amaran jika bertembung dengan slot lain) atau menandanya "Tiada liputan"; boleh ditapis ikut petugas. (Teknikal: slot ketibaan berID `arr-…`; "Tiada liputan" disimpan dalam lajur `tiada_publisiti` tab Status.)
- **Status liputan setiap slot:** (1) gambar telah dimuatnaik di Drive, (2) publisiti telah dilaksanakan / tidak memerlukan publisiti, (3) nota, serta tanda **PRIORITY** untuk slot keutamaan.
- **Dashboard:** kemajuan ikut hari, ikut sukan dan ikut petugas.
- **Petugas (25 orang):** nama, unit, telefon, kamera, gambar dan ketersediaan 1–5 Dis, diisi oleh admin (perlu PIN) terus dalam jadual di tab Petugas. Semasa menetapkan tugasan, setiap petugas ditanda Available / Sebahagian masa / Tidak available dan diberi amaran jika bertembung.
- **Status & nota** hanya boleh dikemas kini oleh admin.

Sumber jadual: *SURYA_2026_Master_Game_Calendar V4 (latest)* — tab Ringkasan Kejohanan dan tab setiap sukan sahaja. Jika bercanggah, tab sukan diutamakan dan perbezaan dicatat pada kad slot. Data petugas dan status disimpan dalam Google Sheet *SURYA 2026 – Data Website Liputan* melalui Google Apps Script (`apps-script/Code.gs`, tanpa PIN).

Maskot: Mimi & Belang, SURYA 2026.
